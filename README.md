# Deel Ops Hub

HR Operations command center built with Next.js and React.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deployment

The app is deployed via Nexus to `jtk-ops-hub-v2.dp.com`. Merging to `main` triggers automatic deployment.

## Tech Stack

- **Next.js 15** (App Router, standalone output)
- **React 19**
- **Tailwind CSS 4**
- **Bootstrap Icons**
